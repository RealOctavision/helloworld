# 중간발표 시각자료

총 27종. 과학적 도식·통계 그래프이며 새 학습이나 추론을 수행하지 않았다.

## 사용 방법

- `png/`: 고해상도 이미지. 일반 자료는 3200×1800(16:9), 논문식 구조도 04P·04Q·04R은 그림에 맞춘 비율이다. PPT에 원본 비율을 유지해 삽입한다.
- `svg/`: 글자를 윤곽선으로 변환한 벡터. 폰트가 없어도 모양을 유지한다.
- `svg_text/`: 텍스트를 유지한 편집용 SVG. Apple SD Gothic Neo 또는 호환 한글 폰트가 필요하다.
- `data/`: 그래프·표의 원본 수치 CSV. 표의 이미지를 편집하려면 이 수치로 PPT 표를 만들 수 있다.
- `index.html`: 전체 미리보기와 다운로드 링크.
- `build_assets.py`: 수치/레이아웃 재생성 원본. 프로젝트 원본 및 matplotlib이 있는 환경에서 실행한다.

## 권장 본문 순서

01 입력 → 02 데이터 → 03 비교 설계 → 04 구조 → 05 증류 → 06 대표 결과 → 07 라벨 수 → 08 서비스 구성 → 09 혼동 → 10 비용.
모델 구조는 04P(교사 전체) → 04Q(잔차 블록 내부) → 04R(학생 전체)을 사용한다. 기존 04는 간단한 개요용이다.
06T는 대표 결과 수치표, 03B는 수행 범위를 설명하는 보조 자료다. 04D·09D·B로 시작하는 자료는 질의응답에 사용한다.

## 해석 주의

- M2/M5 색상과 모델 역할을 그림 사이에서 유지했다.
- 실제 예시가 아닌 패킷 숫자는 01에 설명용 예시로 표시했다.
- %는 점수, %p는 점수 차이. 오차막대는 5개 seed의 표본 SD로 신뢰구간이 아니다.
- Google·Meta 혼동 그림의 부분집합은 나머지 예측을 기타 열에 합산한다. 행 합계는 100%다.
- Meta 전용 모델을 학습한 것은 아니다. 비Google13 안의 6개 Meta 서비스를 표시했다.
- CPU 추론 속도는 모델 내부 벤치마크이며 패킷 대기·수집·전체 전처리를 포함한 실시간 성능이 아니다.
- 4/5월은 프로젝트에서 이미 관찰한 시간차 평가이며 완전히 새로운 외부 평가라고 소개하지 않는다.
- 전체 모델 원장과 원본 실험 기록은 기존 연구 보고서에 보존한다.

## 수치 CSV 읽기

- F1·Accuracy·Precision·Recall은 기본적으로 0–1 값이다. `_pct` 열과 혼동행렬 셀은 0–100%다.
- `_pp`는 퍼센트포인트 차이, SD는 seed 간 표본 표준편차다.
- 표본이 없는 집합의 빈 지표는 0점이 아니라 계산할 수 없는 값이다.
- `all_per_seed_scores.csv`와 `all_paired_differences.csv`에는 개별 seed 수치도 있다.

## 자료 목록

### 01_input · 문제 정의와 PPI 입력
설명용 4패킷 플로우를 30칸으로 패딩한 예시. 실제 표본이나 실제 모델 예측은 아니다.

### 02_data_protocol · 데이터 처리와 시간 분할
1월 학습 후보만 중복·충돌을 정리했다. 서비스 자격은 1월 정제 후 고유 입력 1,000개 이상을 기준으로 확정했다.

### 03B_experiment_matrix · 실험 행렬과 실행 수
빈 칸은 미실행 조건이다. 3개 구성 × 4개 예산의 모든 조합을 실행한 것은 아니다.

### 03_model_map · M0–M5 실험 비교표
신경망은 A100 학습, M0는 CPU 학습. CPU 비용 측정은 학습된 모델의 추론 벤치마크다.

### 04D_architecture_detail · 모델 구조 상세
실제 코드 및 architecture snapshot 기준. 교사의 임베딩·pooling과 학생의 고정 변환·마스킹은 서로 다르다.

### 04P_teacher_architecture · 논문식 구조도 · 교사 전체
M1/M2의 실제 forward 경로. 채널×패킷 표기로 배치 차원을 생략했다. 임베딩 연결 순서는 IPT(10)→DIR(2)→SIZE(20)이며, 448차원 GeM 뒤에 새 Linear(448,C)를 바로 연결한다. 참고 그림의 Feature Refinement 및 공개 wrapper의 256차원 neck은 사용하지 않는다.

### 04Q_residual_bottleneck · 논문식 구조도 · 잔차 블록 내부
현재 교사의 네 블록은 모두 입출력 채널 수가 달라 1×1 Conv+BN projection을 사용한다. Dropout은 잔차 가지의 마지막 BN 이후, 합산 이전이다. 첫 블록 r=0은 Identity이며 모든 stride는 1이다.

### 04R_student_architecture · 논문식 구조도 · 학생 전체
M3/M4/M5의 동일한 구조. 입력은 공통 clip·패딩 후이며 DIR≠0에서 만든 마스크를 각 Conv→ReLU 뒤에 곱하고 pooling 분모에도 사용한다. 실선은 특징, 점선은 마스크 경로다. [B,채널,패킷]에서 B를 생략했다.

### 04_architecture · 교사와 학생 구조 요약
교사는 공개 30pktTCNET backbone을 활용하되 pooled 448차원에 새 분류기를 연결했다. 256차원 wrapper 출력 경로가 아니다.

### 05_distillation · 지식 증류 학습과 추론
교사는 학습 중 동결한다. 교사 logits는 동일 fitting 입력에서 미리 계산해 재사용했다. T=1이어도 전체 분포를 따르는 KL이 남는다.

### 06T_main_results · 대표 성능 결과표
표의 ±는 표본 표준편차. 모델 선택은 2월 검증에서 수행했으며 4·5월은 동결 모델의 평가다.

### 06_main_performance · 대표 조건 성능 그래프
막대 높이는 Macro-F1의 5개 seed 평균. M2−M1에는 초기값 외 선택 학습률·BN 정책 차이도 포함된다.

### 07_label_budget · 라벨 예산별 성능 곡선
평균 성능의 기술적 비교다. 모든 예산에서 동일 50 epoch를 사용하므로 라벨 증가와 연산량 증가를 분리한 실험은 아니다.

### 08_service_cohorts · 서비스 구성별 성능
본문용으로 M2/M3/M5만 강조했다. 6개 모델의 모든 조건별 결과는 데이터 CSV와 기존 보고서에 보존되어 있다.

### 09D_google_M2 · Google 전체 혼동행렬 M2
20개 전체 클래스의 행 정규화 혼동행렬. 숫자 미표시 셀은 0이라는 뜻이 아니다.

### 09D_google_M5 · Google 전체 혼동행렬 M5
20개 전체 클래스의 행 정규화 혼동행렬. 숫자 미표시 셀은 0이라는 뜻이 아니다.

### 09_confusion_focus · Google·Meta 혼동 비교
Google의 6개 서비스는 주요 혼동을 설명하기 위한 부분집합이다. Meta는 비Google13 실험에서 6개 관련 서비스를 뽑은 것이며 Meta 전용 실험이 아니다. 다른 예측 클래스는 기타 열에 보존했다.

### 10_accuracy_cost · 성능과 CPU 추론 비용
SD는 세로축 F1 변동만 표시한다. 개별 seed의 latency median을 평균했으며 통합 측정 중앙값이 아니다. 파라미터 감소는 메모리 RSS 감소와 같지 않다.

### B01_collision · 입력 길이별 충돌
정규화된 순서 있는 입력이 완전히 같고 라벨이 다른 그룹의 기록 비율. 최소 가능 오류율과 다르다.

### B02_overlap · 평가 겹침과 비겹침
겹침은 source ID가 아니라 정규화된 PPI 값의 정확한 일치다. 작은 overlap 집합은 빈 클래스가 많아 전체적인 능력의 지표로 사용하지 않는다.

### B03L_train_validation_loss · 학습과 검증 손실
M3와 M5의 train_loss는 서로 다른 목적함수라서 같은 종류의 손실로 겹쳐 비교하지 않았다.

### B03_validation_curves · 검증 학습곡선
저장된 본실험 50 epoch 기록에서 직접 계산. 수렴이 충분했다는 보장이나 추가 학습 결과가 아니다.

### B04_selection · 설정 선택 근거
LR/leaves는 개발 seed 2개 평균, KD는 교사 2개×seed 2개 평균이다. 최적값의 통계적 확실성을 입증한 실험은 아니다.

### B05_googleonly_n200 · Google 계열20 서비스별 결과표
드문 서비스는 support와 함께 읽는다. 전체 M0–M5·4/5월의 정확한 평균 수치는 all_class_results.csv에 제공한다.

### B05_mixed_n200 · 혼합20 서비스별 결과표
드문 서비스는 support와 함께 읽는다. 전체 M0–M5·4/5월의 정확한 평균 수치는 all_class_results.csv에 제공한다.

### B05_nongoogle_n200 · 비Google13 서비스별 결과표
드문 서비스는 support와 함께 읽는다. 전체 M0–M5·4/5월의 정확한 평균 수치는 all_class_results.csv에 제공한다.

### B06_paired_differences · seed별 짝지은 성능 차이
M2−M1의 평균과 M5−M3/M5−M4의 작은 개선을 각 seed 수준에서 확인한다.
