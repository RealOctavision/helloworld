## 실험 질문과 고정 조건

작은 M3의 표현 능력을 늘리면 성능이 개선되는지 확인했다. 교사 모델과 KD는 사용하지 않고 정답의 cross-entropy로 직접 학습했다.

| 항목 | 기존 M3 | 확대 M3 |
|---|---|---|
| Conv1d 채널 | 3→32→64→64 | 3→64→128→128 |
| 파라미터 수 | 20,180 | 77,204 (약 3.83배) |
| 입력 | 첫 최대 30패킷 IPT·DIR·SIZE | 동일 |
| 나머지 구조 | kernel 3, ReLU, 패딩 마스크, 평균 풀링, 20분류기 | 동일 구현 재사용 |
| 학습량 | Google 포함 20서비스, 서비스당 200/1,000 flows | 같은 seed·예산의 동일 표본 |
| 반복 | 기존 원장에서 seed 201·202 선택 | seed 201·202, 총 4회 학습 |
| 학습 설정 | AdamW, lr 0.003, weight decay 0.0001, batch 128, 50epoch, warm-up 5 + cosine | 동일 |
| 모델 선택 | 2월 검증 Macro-F1 → 낮은 CE → 이른 epoch | 동일 |

서비스당 200개는 총 4,000개, 1,000개는 총 20,000개 학습 흐름이다. 같은 seed에서 200개 표본은 1,000개 표본에 포함된다. 모델 크기가 달라 초기 가중치 자체는 같지 않다.

1월 학습, 2월 검증·체크포인트 선택, 4월 주 평가, 5월 시간 변화 평가를 구분했다. 최종 평가에서 2월로 선택한 `best.pt` 4개를 그대로 사용했다. 평가 결과로 epoch나 모델을 다시 고르거나 재학습하지 않았다.

## 최종 평가 결과

**같은 seed 201·202의 산술평균**이다. 기존 중간발표의 seed 201~205 평균과 섞지 않는다. 전체 표본은 4월 379,194개, 5월 365,258개이며 자연 서비스 분포를 사용한다.

| 평가 월 | 서비스당 학습량 | 정답률: 기존 → 확대 | Macro-F1: 기존 → 확대 |
|---|---:|---:|---:|
| 4월 | 200 | 46.29% → **52.69%** | 33.30% → **38.36%** |
| 4월 | 1,000 | 60.77% → **65.02%** | 46.01% → **50.29%** |
| 5월 | 200 | 45.63% → **52.02%** | 33.57% → **38.50%** |
| 5월 | 1,000 | 59.99% → **64.19%** | 45.84% → **49.94%** |

월별로 seed 201·202 각각을 비교해도 총 8건 모두 두 지표가 개선됐다. 반올림 전 값은 JSON/CSV를 기준으로 한다. 최종 평가 파일의 점수는 **0~1 비율**, `delta_*_pp`는 **%p**이다.

### 공통 미관측 입력의 보조 평가

사전 지정한 모든 학습 seed·최대 예산과 고정 검증 입력의 합집합에 존재하는 **동일 PPI 입력**을 제외했다. 전체·해당 학습과 중복·비중복·공통 미관측의 네 그룹은 기존 코드와 같다.

| 평가 월 | 서비스당 학습량 | 정답률: 기존 → 확대 | Macro-F1: 기존 → 확대 |
|---|---:|---:|---:|
| 4월 | 200 | 46.56% → **52.89%** | 33.52% → **38.47%** |
| 4월 | 1,000 | 60.93% → **65.34%** | 46.10% → **50.45%** |
| 5월 | 200 | 45.89% → **52.20%** | 33.78% → **38.60%** |
| 5월 | 1,000 | 60.11% → **64.48%** | 45.92% → **50.09%** |

4월 376,465개, 5월 362,640개이며 이 그룹에서도 두 seed 평균의 개선이 유지됐다. 기존 평가 월의 부분집합으로, 새로운 외부 데이터셋은 아니다. 전체 4그룹의 지표·혼동행렬·클래스별 점수와 압축 예측은 원본 평가 ZIP에 보관했다. 공개 표는 전체 및 공통 미관측 그룹을 요약한다.

## 학습·2월 검증 결과

2월 검증은 서비스별 균형 표본이며 4·5월 자연분포 평가와 구분한다.

| 서비스당 학습량 | 검증 정답률: 기존 → 확대 | 검증 Macro-F1: 기존 → 확대 | 확대 모델 학습 Macro-F1 |
|---|---:|---:|---:|
| 200 | 46.29% → 51.96% | 45.29% → 51.65% | 64.93% |
| 1,000 | 60.71% → 65.05% | 60.74% → 65.33% | 78.10% |

학습과 검증 Macro-F1 사이에는 두 조건 모두 약 13%p 차이가 남았다. 채널 부족이 유일한 원인이거나 데이터가 충분함을 뜻하지 않는다. 검증 JSON/CSV는 필드 이름에 표시한 대로 **백분율**이며 최종 평가 파일의 0~1 단위와 구분한다.

## 검증한 내용

- 공식 HDF5 크기·SHA-256과 기존 데이터 캐시·분할·NPZ 해시 대조.
- 네 학습의 50epoch 완료, best/last 체크포인트 해시 확인.
- 최종 평가 전 네 best.pt와 선택 epoch 고정. 새로운 런타임의 2월 예측 라벨은 원본과 전부 같고 확률은 `rtol=1e-5`, `atol=1e-6` 이내. 이 단계의 비트 단위 일치는 주장하지 않음.
- 기존 M3와 학습 표본, 평가 입력·라벨·순서 해시, 그룹별 표본 수 및 클래스별 개수 대조.
- 저장된 압축 예측으로 네 그룹의 지표를 재계산해 JSON과 일치 확인.
- 합성 추론, 지표 재계산, 완료 결과 재사용, ID/중복 그룹 오류 및 예측 파일 손상 검사 통과.
- Drive에 복사한 결과 ZIP의 SHA-256·압축 CRC 확인.

공개 수치는 Colab 화면에 표시된 결과를 옮긴 집계 사본이며 비교 대상 원장은 공개 저장소 사본과 추가 대조했다. 원본 ZIP의 로컬 다운로드·로컬 재검증을 완료했다고 주장하지 않는다.

## 환경과 해석 한계

| 실행 | GPU | PyTorch | CUDA |
|---|---|---|---|
| 기존 M3 학습·평가 | A100-SXM4-40GB | 2.11.0+cu130 | 13.0 |
| 확대 M3 학습 | Tesla T4 | 2.11.0+cu130 | 13.0 |
| 확대 M3 최종 평가 | Tesla T4 | 2.14.1+cu130 | 13.0 |

최종 추론은 FP32, TF32 비활성화, batch 1,024이다. GPU·패키지 차이가 남아 있어 모든 개선을 채널 변경만의 순수 인과 효과로 확정하지 않는다.

- 두 seed의 탐색 결과다. 추가 seed나 통계적 확정을 위한 실험은 하지 않았다.
- 50epoch 고정에서 200개 조건은 1,600회, 1,000개는 7,850회 업데이트다. 학습량을 고정한 순수 데이터량 비교가 아니다.
- 4·5월은 이전 프로젝트에서도 확인한 평가 월로, 새로운 외부 블라인드 평가가 아니다. 이후 이 결과로 추가 튜닝한다면 새로운 미관측 데이터로 최종 일반화 성능을 확인해야 한다.
- 확대 모델은 파라미터가 약 3.83배 늘었다. CPU 지연·처리량·메모리는 이번에 측정하지 않아 성능 대비 배포 효율까지 개선됐다고 주장하지 않는다.
- 교사 개선·KD·새 클래스·미등록 서비스 평가는 수행하지 않았다.

## 원본 보관과 재현

원본은 프로젝트 Drive의 `QUIC_M3_results`에 보관했다. 공개 저장소에는 원시 데이터·개별 흐름 예측·가중치·개인 Colab 링크를 넣지 않았다. 팀원은 담당자에게 검증된 학습 ZIP을 받아 평가 전용 노트북을 사용할 수 있다. ZIP 이름·크기·해시는 [artifact_manifest.json](artifact_manifest.json)에 있다.

학습·평가 Python 파일은 실제 실행본을 보존했다. 공개용 노트북은 출력과 계정 정보를 제거한 실행 템플릿이다. 평가 전용 노트북은 실행한 셀과 코드를 조립한 뒤 구문·내장 코드 일치를 확인했으며 조립한 노트북 전체를 GPU에서 다시 실행하지는 않았다.
